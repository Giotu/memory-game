# memory-game

A matching game: the player reveals cards and memorizes their positions in order to find all the matches in the fewest possible moves.

## Tech Stack

- HTML5
- CSS
- JavaScript
- Vite
- modern-normalize
- ESLint
- Stylelint
- Prettiers

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```
